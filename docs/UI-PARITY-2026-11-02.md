## Remaining visual differences identified from source

These are current differences from source inspection and the production screenshots described below:

1. Glass blur, shadows, mesh scaling across aspect ratios and motion remain approximated by solid surfaces and a static backdrop. The dark login card/fields are visibly lighter than the reference, and card spacing/vertical placement differ. The login action remains `Continue`, and the preview link is additional to the reference sign-in card.
2. The conversation/options menu is still a centered sheet of buttons, not the reference desktop popover. The composer's plus button opens that combined options sheet instead of the reference attachment menu with its exact ordering and feature colors. Desktop retains a full-width jump-to-latest button.
3. Messages retain sender text in direct chats and a visible 44px message-action control in the metadata row. These make the captured bubbles taller than the reference. The composer is also taller; its empty state displays a disabled send icon instead of the reference microphone. The reference beginning-of-conversation notice is absent in the captured fixture. System notices, reactions, poll controls and attachment actions are not visually identical.
4. The phone list repeats `Chats` below the app header and places the new-chat action there instead of the reference floating action button. Filters are taller and scroll horizontally; the reference fixture fits four smaller filters in one row. Chat-list preview kind icons and the reference dedicated locked-chats row differ; Universal exposes a Locked filter. Navigation includes an Admin shortcut on phones and an explicit sign-out icon, so its composition differs from the reference.
5. Rich-message text/link styling, some empty states, and unreviewed settings/vault/admin layouts still differ. Loading the correct Inter weights does not prove every component uses the matching font/size.
6. This UI role has not performed native/iOS screenshot comparisons, automated pixel diffs, or a complete visual review of every feature screen. Native functional smoke tests and the broader browser suite belong to the main integration report.

## Asset provenance
